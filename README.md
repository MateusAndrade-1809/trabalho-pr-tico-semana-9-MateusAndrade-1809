# Mini Ecommerce do Mateus

Aluno: Mateus Andrade  
Matricula: 1809

## Descricao

Trabalho da semana 9 feito para praticar funcoes e manipulacao do DOM com JavaScript. Montei um catalogo simples de produtos, com busca, filtro por categoria, detalhes do produto e botao para destacar o card.

## Funcionalidades

- O catalogo comeca mostrando 8 produtos.
- As categorias aparecem automaticamente no select.
- A busca filtra pelo nome do produto.
- O filtro por categoria funciona junto com a busca.
- O botao "Ver detalhes" mostra as informacoes completas do produto.
- O botao "Destacar" muda a aparencia do card.
- No codigo foram usados `getElementById`, `querySelector`, `querySelectorAll`, `innerHTML`, `createElement`, `setAttribute`, `appendChild`, `classList.add`, `style` e `addEventListener`.
